# Матрица: бухгалтерия 3.0 (8.5.1.1529)

Вторая конфигурация для проверки общности правил:
`Accounting_3_0_199_13.cf` (750 МБ), база `ibcmd_acc2`, платформа
8.5.1.1529, формат XML 2.21.

## Замер (выгрузка прервалась)

| Показатель | Значение |
|---|---|
| Файлов у нативного | 94 159 |
| Файлов у `ibcmd-rs` | 4 689 |
| Совпали | 4 602 |
| Различаются | 87 |
| Только у нативного | 89 470 |

Нативная выгрузка — 165 с. Наша завершилась с ошибкой на 4 689-м файле:

```
failed to extract spreadsheet template from source asset
Reports\РегламентированныйОтчетБухОтчетностьМП\Templates\
ФормаОтчета2012Кв4_Пояснения2\Ext\Template.xml:
MXL decoder [mxl.decoder.binary-container]: invalid MXL body:
MOXCEL language descriptor has an unknown layout
```

То есть выгрузка **останавливается** на шаблоне с неизвестной раскладкой
MOXCEL — это fail-closed, а не молчаливая потеря: 89 470 файлов не записаны
именно из-за этого.

## Вторая находка: заголовки вида `{2,…}`

До остановки модель уступала legacy-конвертеру на строках с заголовком
`{2,{1,0,<uuid>},"Имя",…}`:

```
not an md header: {2,{1,0,<uuid>},"ФормаОтчета2015Кв1_ФормаОтчета",{…
not a Subsystem record: {21,{2,{1,0,<uuid>},"МаршрутыПодписания",…
```

Это не заголовок `{3,…}`, который ожидает общая модель. В бухгалтерии такие
записи есть у форм отчётов и подсистем; в ServiceDesk их не было. Нужно
понять, что это за вариант (вероятно, «заблокированные»/старые объекты) и
научить модель читать его, а не отдавать legacy-конвертеру.

## Прогресс

1. **Языковой дескриптор ревизии 6 починен.** Запись
   `{8,1,6,{"ru","ru",1,1,"ru","Русский","Русский"},…}` хранит язык в короткой
   форме (`count*3+4`) — так же, как ревизии 8 и 9. Условие расширено на
   ревизии `6|8|9`, тест `revisions_8_and_9_read_the_short_language_record`
   дополнен ревизией 6. Выгрузка прошла этот шаблон.
2. **Следующий барьер** — графическая схема:
   `failed to extract graphical scheme from source asset
   Reports\АнализСостоянияНалоговогоУчетаПоУСН\Templates\МакетКарты82\Ext\Template.xml`
   (без подробностей). Выгрузка дошла до 4 713 файлов.

## Следующие шаги

1. Разобрать графическую схему `МакетКарты82`: чем её запись отличается от
   поддерживаемых.
2. Научить модель заголовку `{2,…}`.
3. Повторить матрицу до полного прохода, затем сравнить побайтово.
